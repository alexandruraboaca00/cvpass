# Security policy

CVPass **0.1.x** is the currently supported release line. This does not imply
an automatic update service or a guaranteed response deadline.

No dedicated private security email or reporting channel has been established.
If GitHub's private vulnerability reporting is available for the repository,
use its Security tab to report privately. Otherwise, open only a minimal issue
requesting a private contact method; **do not post vulnerability details or
sensitive attachments publicly**. Do not invent or assume an email address.

Useful information: CVPass version, Linux distribution/architecture, reproducible
steps using synthetic files, expected/actual behavior and sanitized diagnostics.
Never attach real CVs, personal XML/PDFs/photos, private databases, backup bundles,
credentials or unredacted logs. Do not publish another person's information.

CVPass is designed to process and store CV data locally and operate offline,
without telemetry, cloud upload or CDN resources. Unexpected network activity,
unsafe import execution, data loss or leakage of excluded/private PDF content
should be reported. Until a private channel exists, withhold sensitive details.
