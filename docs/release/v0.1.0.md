# English

## CVPass 0.1.0 — first public release (draft, not published)

A private, offline CV editor for Linux, inspired by Europass workflows.

- Desktop AppImage for **Linux x86_64**; no Node/npm/dev server required by users.
- Local library, reusable Master Profile and independent CVs created by selection.
- Eight areas: personal information, education, work, skills/groups, languages,
  certifications, projects and multiple custom sections.
- Spanish/English interface and reviewed manual document-language workflows.
- Original **Simple** and **Lateral** templates, real PDF.js preview and export
  of the same PDF bytes.
- Structured import with review: own PDF payloads/projects and the tested partial
  Europass PDF/XML subset. No claim of universal Europass compatibility.
- Editable `.cvproj` projects, complete workspace backup/restore, drafts, recovery,
  checkpoints and local revision history.
- Local processing, no accounts, telemetry, cloud upload, CDN or auto-update.

### Install and start

Place `CVPass-0.1.0-x86_64.AppImage` and `SHA256SUMS` together:

```sh
sha256sum -c SHA256SUMS
chmod +x CVPass-0.1.0-x86_64.AppImage
./CVPass-0.1.0-x86_64.AppImage
```

If FUSE mounting is unavailable, use
`APPIMAGE_EXTRACT_AND_RUN=1 ./CVPass-0.1.0-x86_64.AppImage`.
Do not disable Chromium sandbox. Compatible desktop Linux systems are the target,
not all distributions/platforms. Create or import a CV, review, Confirm, then
choose Simple/Lateral and export PDF or a portable project. Updating CVForge
keeps the historical `CVForge` data directory and compatible formats.

### Limits and release readiness

No Windows/macOS/mobile support, OCR, generic PDF reconstruction, production
machine translation, universal Europass import, cloud/sync or extra templates.
PDF/UA and complete accessibility are not certified. A PDF recovers only its
visible export; use `.cvproj` for the complete private project. Large history
read/copy cost remains documented. The selected icon master is still awaited;
this provisional package retains Electron's default icon and is not ready to
publish as the final branded release.

# Español

## CVPass 0.1.0 — primera release pública (borrador, no publicada)

Un editor de CV privado y offline para Linux, inspirado en los flujos de trabajo
de Europass.

- AppImage de escritorio para **Linux x86_64**, sin Node/npm/servidor de desarrollo
  necesarios para el usuario.
- Biblioteca local, Perfil maestro reutilizable y CV independientes por selección.
- Ocho áreas: datos personales, educación, experiencia, habilidades/grupos,
  idiomas, certificaciones, proyectos y varias secciones personalizadas.
- Interfaz español/inglés y cambios de idioma del documento manuales y revisados.
- Plantillas originales **Simple** y **Lateral**, preview PDF.js real y exportación
  de exactamente los mismos bytes.
- Importación estructurada con revisión: proyectos/payloads propios y subconjunto
  parcial Europass PDF/XML probado, sin compatibilidad universal.
- Proyectos editables `.cvproj`, backup/restauración completa de workspace,
  borradores, recuperación, checkpoints e historial local.
- Procesamiento local, sin cuentas, telemetría, cloud, CDN ni auto-update.

### Instalar y comenzar

Coloca `CVPass-0.1.0-x86_64.AppImage` y `SHA256SUMS` juntos:

```sh
sha256sum -c SHA256SUMS
chmod +x CVPass-0.1.0-x86_64.AppImage
./CVPass-0.1.0-x86_64.AppImage
```

Si FUSE no permite montar, utiliza
`APPIMAGE_EXTRACT_AND_RUN=1 ./CVPass-0.1.0-x86_64.AppImage`.
No desactives el sandbox. El objetivo son escritorios Linux compatibles, sin
prometer todas las distribuciones/plataformas. Crea o importa, revisa, confirma,
elige Simple/Lateral y exporta PDF o proyecto portable. Al actualizar desde
CVForge se conservan el directorio `CVForge` y los formatos compatibles.

### Límites y preparación

Sin Windows/macOS/móvil, OCR, reconstrucción PDF genérica, traducción automática
de producción, importación Europass universal, cloud/sync ni más plantillas.
PDF/UA y accesibilidad completa no certificados. El PDF recupera solo su versión
visible; `.cvproj` conserva el proyecto privado completo. Permanece documentado
el coste de lecturas/copias con historiales grandes. Falta el icono maestro
seleccionado: el paquete provisional conserva el icono de Electron y no está
listo para publicarse como release de marca definitiva.
