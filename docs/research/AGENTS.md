# AGENTS.md

## Objetivo del proyecto
Construir una herramienta propia para crear y gestionar CVs inspirada en el flujo de Europass.

## Fase actual
Estamos en fase de investigación y reverse engineering funcional con REA.

## Reglas
- No implementar todavía salvo que se pida explícitamente.
- No copiar código propietario ni recursos de Europass.
- Usar REA para observar comportamiento, estructura y UX.
- Separar siempre hechos observados, inferencias y dudas.
- Guardar los análisis en `docs/research/`.
- Priorizar observación de UI, navegación, formularios, validaciones, vista previa y exportación.
- No asumir estructuras internas que no hayan sido observadas.

## Flujo de trabajo
1. Observar una pantalla o interacción con REA.
2. Documentar hallazgos.
3. Validar comportamiento.
4. Solo después diseñar nuestra arquitectura.
5. Implementar cuando la investigación sea suficiente.
